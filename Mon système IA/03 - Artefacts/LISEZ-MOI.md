# Artefacts

Ici, l'IA range ce qu'elle produit avec vous. Un sous-dossier par type de production :

- `Brainstorms/` : les comptes rendus du skill **challenge**.
- `Rapports/` : les livrables des skills, par exemple l'étude de marché (un fichier `.md` et une page `.html`).

Un artefact porte toujours sa date au début de son nom : `AAAA-MM-JJ - Sujet`. Vous pouvez créer d'autres sous-dossiers quand un nouveau type de production apparaît.
