# EDM-M14 · Mon système IA

Le second cerveau des apprenants du module 14 (École des Métiers GBH) : un dossier de fichiers texte (`.md`), à ouvrir avec Obsidian, que l'IA relit pour travailler avec vous.

**Pour commencer** : ouvrez [Mon système IA/LISEZ-MOI.md](<Mon système IA/LISEZ-MOI.md>).

## Les skills
| Skill | À quoi il sert |
|---|---|
| `socratique` | m'aide à trouver mes propres réponses, une question à la fois |
| `challenge` | met mon travail à l'épreuve et en garde un compte rendu |
| `ton` | crée mon fichier `ton.md` (ma façon d'écrire) |
| `valeurs` | découvre mes valeurs (méthode Demartini) |
| `demandes-clients` | prépare une réponse aux demandes et réclamations de clients B2B |
| `etude-de-marche` | mène une étude de marché sourcée, en trois temps |

## Récupérer le dossier
- **Sans Git** : bouton vert **Code** > **Download ZIP**, puis décompressez.
- **Avec Git** : `git clone https://github.com/valentinffrench/EDM-M14.git`

Le dossier à ouvrir dans Obsidian est `Mon système IA`.
